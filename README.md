GetReplies.ai — Chrome/Edge extension

A tiny extension that injects `content.js` into configured hosts (e.g. LinkedIn) and runs a background service worker (`background.js`).

Install (Load unpacked)
1. Open chrome://extensions/ (or edge://extensions/).
2. Enable Developer mode → Load unpacked → select this folder.

Quick use
- Open a matching site (see `manifest.json` hosts). `content.js` runs at page load.

Files
- `manifest.json`, `background.js`, `content.js`, icons
